### Provenance

An unmodified **Official PBMC** should retain the provenance displayed on the canvas rather than having Platform Generation attribution removed or replaced.

An adapted PBMC may carry the adapter's own branding, but the PBMC attribution must remain clearly visible and the adapted work must not be presented as an **Official PBMC**.

## 3. Platform Generation branding and Official PBMC

Platform Generation logos and the **Official PBMC** designation are not included in the Creative Commons licenses.

They may not be used in a way that falsely suggests that an adapted canvas, publication, product or service is produced, approved or endorsed by Platform Generation.

Third-party names and trademarks appearing in case studies remain the property of their respective owners.

## 4. Software

The repository's software/build code is publicly viewable so the public PBMC Library can operate transparently. No open-source software license is granted for that code unless a separate software LICENSE file explicitly states otherwise.

## Plain-language summary

You may:

- use the PBMC;
- show it in presentations and papers;
- teach with it;
- use it in workshops and consulting;
- create your own PBMC cases;
- adapt the canvas;
- use the case data with attribution.

Please do not:

- remove the PBMC origin and present the same framework as your own invention;
- replace the provenance on an unmodified Official PBMC so that it appears to originate elsewhere;
- label your adaptation **Official PBMC**;
- use Platform Generation branding to imply endorsement.

This summary explains the intended reuse model. The applicable Creative Commons license terms govern the materials licensed under them.
