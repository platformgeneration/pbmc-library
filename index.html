The framework

Platform Business Model Canvas

The PBMC makes platform ecosystems visible. It maps the Consumer, Provider, Partner and Owner perspectives around a core value unit and shows how jobs, gains, pains, governance, access, resources, activities and core transactions fit together. The aim is not merely to describe a company, but to understand how value is orchestrated across an ecosystem.
